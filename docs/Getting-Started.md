# 🚀 快速开始

> **版本提示（0.0.3-pre-alpha）**：当前版本**尚无任何人工撰写的可用工作流**。
> 它提供的是一种**体验“逻辑向 AI”的方式**——输入一句话，让模型规划出一棵可执行的多层 DAG。
> 质量尚粗糙（且会浪费较多 token），但相对裸模型直答，质量与可管控复杂度提升显著。

本页帮你在最短时间内跑起来并体验规划能力。开发者读完本页后请继续阅读 [[工作流开发总览|Developer-Guide]]。

## 1. 安装

Unigen 是 Electron 桌面应用，支持 **Windows / Linux / macOS**。

- **推荐方式**：从 [Releases](https://github.com/masol/unigen/releases)
  下载对应平台的**免安装版**，解压后直接执行。
- **从源码构建**：见 [[本地环境配置|Local-Setup]]。

### 系统要求：先决定你的模型策略

| 策略                                      | 本地负载                          | 参考配置                                 | 适合                          |
| ----------------------------------------- | --------------------------------- | ---------------------------------------- | ----------------------------- |
| **全部使用外部模型 API**（禁用内建模型）  | 仅 SQLite + LanceDB，数据规模不大 | 4 核 CPU / 8GB 内存 / 2GB 磁盘，无需 GPU | **推荐**                      |
| **启用内建模型**（嵌入 / 重排等本地运行） | 取决于所选模型                    | 由你的机器配置决定可用模型               | 有硬件、想省 API 或离线的用户 |

启用内建模型时，推荐用 [llmfit](https://github.com/AlexsJones/llmfit)评估你的机器能跑什么规模的模型。注意：llmfit 不直接提供嵌入/重排模型的自动推荐，需要参考其显存/内存换算方法自行估算。

## 2. 配置模型（一次即可，全项目通用）

首次启动后，点击**左下角设置**，配置你的模型：

| 模型     | 是否必须 |
| -------- | -------- |
| 文本模型 | **必须** |
| 嵌入模型 | **必须** |
| 重排模型 | 推荐     |

这些设置**只需配置一次**，适配全部项目类型。

**强烈建议**：同样在左下角设置里配置 **OpenTelemetry 接收器 URL**（如 [Phoenix](https://github.com/Arize-ai/phoenix)），以便拿到规划与执行的全量日志——这对理解和排查规划过程非常有用。

## 3. 新建你的第一个项目

新建项目时需要选择**项目类型**：

- **空白项目**——内建工作流开发能力，也是当前体验规划的入口。
- 其余项目类型作为**目标占位**存在，尚无成熟可交付工作流（见 [[路线图|Roadmap]]）。

> **注：当前版本默认信任代码，模板来源校验、恶意代码防护能力较弱，请勿安装来源不可信的项目模板。**

## 4. 体验规划：让 AI 规划一棵可执行的 DAG

这是当前版本最核心的体验。打开任意项目后，点击**右侧面板**展开反思助手（必须有项目打开），执行：

```
/plan --no-codegen=on --cap=new "这里输入你的要求，例如：从剧本到视频"
```

- `--no-codegen=on`：先只做规划、暂不生成代码。
- `--cap=new`：新建一个能力（规划目标）。

规划耗时较长且会落库存储，属正常现象——原理见 [[逻辑向AI：维度、坐标系与两种逼近|Logic-Oriented-AI]]（当前仅实现约 1% 的功能，只做可行性校验，质量校验等等都尚未实现）。

### 查看规划结果

1. 右侧面板切换到 **蓝图 → 术语表**，用 `.`（点）过滤（空白项目仅一个候选）。
2. 点击左侧三竖线的 **Action Button → 面板显示**。
3. 左下方即可看到 AI 针对你输入规划出的**多层 DAG 树**。

### 执行规划

1. 在 DAG 工具栏**录入原始数据**。
2. 点击**执行**。
3. 若报“未找到 XX 能力”，说明该节点尚未生成代码——去掉 `--no-codegen`、执行 `/plan --cap=XXX(节点ID)` 补齐即可。

你可以随时**查看和编辑节点的代码及元信息**。

## 5. 体验推理能力（Prism）

`/prism` 不落库存储，可直观对比 **Prism 与模型直答的差异**：

```
/prism 给我几个简短的面巾纸的爆笑广告创意
```

原理与实测案例见 [[棱镜推理|prism]]（第十节就是这个例子的实录）。
