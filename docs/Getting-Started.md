# 快速开始

---

## 1. 安装

从 [Releases](https://github.com/masol/unigen/releases) 下载免安装版，解压即用。从源码构建：见 [[本地环境配置|Local-Setup]]

---

## 2. 配置模型（一次，全局生效）

**左下角设置** → 配置文本模型（必填）、嵌入模型（必填）、重排模型（推荐）。

---

## 3. 创建项目——所有项目类型操作一致

**关键认知**：所有项目类型的操作完全一致——选择类型、填输入、点运行。**区别只有"输入是什么"**：

| 项目类型       | 输入                 | 产出           |
| :------------- | :------------------- | :------------- |
| 产品 → 电商图  | 产品说明             | 电商图         |
| 剧本 → 视频    | 剧本                 | 视频           |
| **工作流工坊** | **《岗前培训手册》** | **新项目类型** |

"工作流工坊"的输入不是普通数据，是"如何做这件事"的人类经验——产出是新的项目类型。

---

## 4. 运行

打开项目，点击运行图标，执行完成后会通知。

---

## 5. 推荐第一个体验

**"产品说明 → 产品电商图"**——链条短、成本低、几分钟出结果。

新建项目 → 选择该项目类型 → 填写产品说明 → 点运行。
