# 🎯 欢迎来到 Unigen

**Unigen = 把人类工作流编译成 AI Agent。**

适合 **复杂、长链条、要求高质量但不要求灵活** 的任务——比如剧本到成片、创意到小说、需求到代码。

不适合 **短平快、对话式、需要边执行边探索** 的任务——那是 Agentic Agent 的主场。

---

## 这是什么：Predefined Workflow Agent

Unigen 运行的是 **预定义工作流** ，不是"每次即兴发挥"的自主 Agent。
虽然即兴发挥的自主Agent是工作流的一种，鉴于当前模型能力，不推荐使用自主Agent式的工作流。

| | Agentic Agent | Unigen Agent |
|:---|:---|:---|
| 执行方式 | 每次"即兴发挥"，边走边想 | 按编译好的工作流执行，路径确定 |
| 质量来源 | 模型能力 | 人类工作流 |
| 长链条 | 容易漂移、捏造 | 逻辑骨架约束，不漂移 |
| 模型要求 | 强模型才稳定 | 弱模型也能稳定 |

**一句话**：Unigen 用"不灵活"换"确定性强且可审计"。一旦工作流设计好，弱模型也能跑出稳定质量。
