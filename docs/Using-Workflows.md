# ▶️ 运行你的第一个工作流（创作者指南）

本页面向**使用**工作流的创作者。你不需要写代码，也不需要理解规划器原理。

> **版本提示（0.0.3-pre-alpha）**：当前版本**尚无成熟可交付的人工工作流**。
> 本页描述的是 Unigen 面向创作者的**目标使用形态**；若你想现在就动手，请看文末「当前能体验什么」。

## 工作流是什么

在 Unigen 里，一个工作流 = 一条把你的输入（剧本、创意、素材……）逐步加工成最终成品（视频、小说……）的完整流水线。它可能包含几十上百个步骤，运行数小时到数天——Unigen 负责让它**稳定地跑完，且质量不崩**。

## 获取工作流（目标形态）

工作流以**项目类型**的形式分发：

- 开发者可以把打磨好的工作流导出为新的项目类型并发布，你导入后即可像内建类型一样使用。
- 随 [[路线图|Roadmap]] 推进，会逐步落地剧本→视频、创意→小说等真实价值工作流。

## 配置与运行（目标形态）

1. **配置**：工作流的可配置项通过**侧边动态面板**呈现——项目名称、分辨率、叙事节奏、参考图等，都在面板里直接填写和调整。
2. **运行**：打开项目后，点击界面上的**运行图标**即可。
3. **完成**：执行结束会有提示，可查看日志确认各环节的执行情况。

长时间执行是这类任务的常态，对时间不敏感、对质量零容忍，正是 Unigen 的设计场合。

## 当前能体验什么（0.0.3-pre-alpha 实况）

虽然还没有成熟工作流，你现在就可以体验 Unigen 的**规划能力**——让 AI 从一句话规划出一棵可执行的多层 DAG：

1. 新建项目 → 打开右侧面板 → 切换到反思助手。
2. 执行 `/plan --no-codegen=on --cap=new "从剧本到视频"`。
3. 在「蓝图 → 术语表」用 `.` 过滤，通过 Action Button → 面板显示查看 DAG，录入原始数据后执行。

详细步骤见 [[快速开始|Getting-Started]] 第 4 节。
